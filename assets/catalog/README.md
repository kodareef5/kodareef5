# Generated project gallery

Run `./build-readme.py` to regenerate these labels, or `./build-readme.py --check`
to check them without writing. `catalog_assets.py` owns the layout.

Each light/dark SVG embeds an **unchanged official logo file** and places the
project name below it. Marks are not redrawn or recolored. The images keep each
logo and name together when GitHub wraps the gallery; the links have descriptive
alternative text. Projects without a suitable mark retain ordinary text links.

Original files and provenance are in [the logo directory](../logos/README.md)
and [projects.json](../../projects.json). Marks retain their owners’ rights.
